# 🍎 Fruit Image Classifier

A CNN-based image classifier that identifies 10 types of fruits using Deep Learning.

## 🔧 Tech Stack
- Python, TensorFlow, Keras
- Google Colab
- Fruits-360 Dataset (Kaggle)

## 🍓 Fruits Classified
Apple, Banana, Cherry, Grape, Kiwi, Lemon, Mango, Orange, Pineapple, Strawberry

## 📊 Results
- ✅ Test Accuracy: ~95%
- 🧠 Model: Custom CNN (3 Conv blocks)

## 🚀 How to Run
1. Open `Image_Classifier_for_Fruits.ipynb` in Google Colab
2. Run all cells in order
3. Upload your own fruit image to test!

## 📁 Dataset
[Fruits-360 on Kaggle](https://www.kaggle.com/datasets/moltean/fruits)
